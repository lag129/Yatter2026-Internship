# templatesディレクトリ
このディレクトリはOpenApi Generatorで生成されるコードを一部修正するために使用されるテンプレートファイルを格納しています。  
Generatorが生成するコードは古いバージョンの情報を利用している場合があり、最新の実装に合わせるためにテンプレートを修正しています。  
講義を受ける方が修正する必要はありません。  

## テンプレートリポジトリ/リファレンスリポジトリを保守される方へ
OpenApi Generator の更新の都合でテンプレートの内容が古くなる可能性が高いです。  
テンプレートのコピー元は以下のURLにあります。  
https://github.com/OpenAPITools/openapi-generator/tree/master/modules/openapi-generator/src/main/resources/kotlin-client  
必要な内容をコピーして、テンプレートディレクトリに配置してください。

### テンプレの改変ポイント
#### build.gradle
使用するライブラリがバージョンカタログを参照するように修正しています。  
また、不要な公開関連のコードを削除しています。  
構成要素を変えない限りはここを更新する必要性は低いと思います。

#### ApiClient
defaultBasePathのURLをエミュレータのローカルホストに接続できるように変更しています。  
この修正を忘れるとエミュレータからAPIサーバーに接続できないため、注意してください。

#### licenceInfo
リンターの警告が出ないよう、抑制リストに一部追加しています。  
更新する際は必要に応じて抑制リストを更新してください。

#### その他
licenceinfo を参照し、リンターの警告が出ないように調整しています。  
更新する際は、テンプレートの先頭に以下の内容を追記してください。
```mustache
{{>licenseInfo}}
```
