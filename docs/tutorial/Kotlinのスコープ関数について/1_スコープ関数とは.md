# Kotlinのスコープ関数について

Kotlinには **スコープ関数（Scope Functions）** と呼ばれる標準ライブラリ関数が用意されています。  
スコープ関数は **オブジェクトに対してコードブロックを実行する** 関数で、`let`・`run`・`with`・`apply`・`also` の5種類があります。

いずれもラムダ（`{ ... }`）の中でオブジェクトを操作できる点は共通ですが、**ブロック内でのオブジェクトの参照方法**と**戻り値**が異なります。

---

## 比較マトリクス

| 関数 | ブロック内の参照 | 戻り値 | 典型的な用途 |
|------|:---:|:---:|------|
| `let` | `it` | ラムダの結果 | null チェック後の変換・処理 |
| `run` | `this` | ラムダの結果 | オブジェクトの設定と結果の取得 |
| `with` | `this` | ラムダの結果 | 既存オブジェクトへの複数操作（拡張関数でない） |
| `apply` | `this` | レシーバーオブジェクト自身 | オブジェクトの初期化・設定 |
| `also` | `it` | レシーバーオブジェクト自身 | 副作用（ログ出力、デバッグなど） |

**ポイント**

- ブロック内で `this`（レシーバー）として参照 → `run` / `with` / `apply`
- ブロック内で `it`（引数）として参照 → `let` / `also`
- 戻り値がラムダの結果 → `let` / `run` / `with`
- 戻り値がレシーバー自身 → `apply` / `also`

---

## 各関数の説明

### `let`

```kotlin
// ブロック内で it としてオブジェクトを参照し、ラムダの最後の式が戻り値になる
val upperName = "alice".let { it.uppercase() } // "ALICE"
```

**特徴**
- ブロック内では `it` でオブジェクトを参照（別名を付けることも可能）
- ラムダの最後の式が戻り値になる

**最もよく使われる用途：null チェック後の処理**

`?.let { }` のパターンを使うと、オブジェクトが null でないときだけブロックを実行できます。

```kotlin
// avatar が null でなく、かつ空文字でもない場合だけ URL を生成する
val avatarUrl: URL? = apiUser.avatar?.takeIf { it.isNotEmpty() }?.let { URL(it) }
```

> 💡 **Yatter での使用例**  
> `UserConverter.kt` でAPIから取得した文字列を `URL` 型に変換する際に使われています。

**null チェックなしの変換にも使える**

```kotlin
val username = "user123"
val upperCase = username.let { it.uppercase() } // "USER123"

// it に別名を付けることもできる
val length = username.let { name -> name.length } // 7
```

### `run`

```kotlin
// ブロック内で this としてオブジェクトを参照し（省略可能）、ラムダの最後の式が戻り値になる
val greeting = StringBuilder().run {
    append("Hello")
    append(", World")
    toString() // この戻り値が greeting に入る
}
// greeting = "Hello, World"
```

**特徴**
- ブロック内では `this` でオブジェクトを参照（`this.` は省略可能）
- ラムダの最後の式が戻り値になる

---

### `with`

```kotlin
// with はオブジェクトを第1引数に渡し、ブロック内で this として参照する（拡張関数ではない）
val description = with(user) {
    "$name は $age 歳です" // this.name, this.age の省略形
}
```

**特徴**
- `run` と似ているが、拡張関数ではなく通常の関数（オブジェクトを第1引数に渡す）
- ブロック内では `this` でオブジェクトを参照（`this.` は省略可能）
- ラムダの最後の式が戻り値になる

**使用例**

```kotlin
data class User(val name: String, val age: Int)

val user = User("Alice", 25)
val description = with(user) {
    "$name は $age 歳です" // this.name, this.age の省略形
}
```

---

### `apply`

```kotlin
// ブロック内で this としてプロパティを設定し（省略可能）、レシーバー自身が戻り値になる
val logging = HttpLoggingInterceptor().apply {
    level = HttpLoggingInterceptor.Level.BODY
}
// logging には設定済みの HttpLoggingInterceptor インスタンスが入る
```

**特徴**
- ブロック内では `this` でオブジェクトを参照（`this.` は省略可能）
- 戻り値は**レシーバーオブジェクト自身**（ブロック内の最後の式ではない）
- オブジェクトの初期化・設定に使うのが典型的なパターン

> 💡 **Yatter での使用例①（デバッグ・ログ設定）**  
> `3_デバッグの仕方.md` のサンプルコードで `HttpLoggingInterceptor` に対してログレベルを設定する際に使われています。

```kotlin
// APIクライアントの認証設定
single<ImagesApi> {
    ApiClient().apply {
        addAuthorization("Auth", get<TokenInterceptor>())
    }.createService(ImagesApi::class.java)
}
```

> 💡 **Yatter での使用例②（DI設定）**  
> `InfraModule.kt` で `ApiClient` に認証インターセプターを追加してから `createService` を呼ぶ際に使われています。  
> `apply` はレシーバー自身を返すため、`.apply { ... }.createService(...)` のようにメソッドチェーンが書けます。

---

### `also`

```kotlin
// ブロック内で it としてオブジェクトを参照し、レシーバー自身が戻り値になる
val numbers = mutableListOf(1, 2, 3)
    .also { println("処理前: $it") } // ログを出力してからリストを返す
// 処理前: [1, 2, 3]
// numbers = [1, 2, 3]
```

**特徴**
- ブロック内では `it` でオブジェクトを参照
- 戻り値は**レシーバーオブジェクト自身**
- 副作用（ログ出力、バリデーションなど）を追加するのに使うのが典型的なパターン

**使用例**

```kotlin
val list = mutableListOf(1, 2, 3)
    .also { println("元のリスト: $it") } // ログを挟む
    .also { it.add(4) }                  // 要素を追加
// 元のリスト: [1, 2, 3]
// list = [1, 2, 3, 4]
```

## 使い分けのガイド

```
オブジェクトを使って何か別の値を作りたい
├── null チェックも兼ねたい     → ?.let { }
├── this で書きたい              → .run { }
└── 引数形式で渡したい           → with(obj) { }

オブジェクト自身を返してほしい（チェーンを続けたい）
├── this で設定・初期化したい    → .apply { }
└── it でログや副作用を追加したい → .also { }
```

### 迷ったときのシンプルな判断基準

| やりたいこと | 使う関数 |
|---|---|
| null チェックをして変換したい | `let` |
| オブジェクトを設定・初期化して返したい | `apply` |
| ログや副作用をはさみたい | `also` |
| オブジェクトを使って別の値を算出したい | `run` または `with` |

---

## よくある書き方の比較

`apply` と `also` は似ていますが、オブジェクトの参照方法が違います。

```kotlin
// apply: this でアクセスできるので this を省略できる
val builder = AlertDialog.Builder(context).apply {
    setTitle("タイトル")   // this.setTitle(...) の省略
    setMessage("メッセージ") // this.setMessage(...) の省略
}

// also: it でアクセスする
val builder2 = AlertDialog.Builder(context).also {
    it.setTitle("タイトル")
    it.setMessage("メッセージ")
}
```

## まとめ

| 関数 | ブロック内の参照 | 戻り値 | 主な用途 |
|------|:---:|:---:|------|
| `let` | `it` | ラムダの結果 | null チェック後の変換 |
| `run` | `this` | ラムダの結果 | 設定＋値の取得 |
| `with` | `this` | ラムダの結果 | 複数操作（拡張関数でない形式） |
| `apply` | `this` | レシーバー自身 | オブジェクトの初期化・設定 |
| `also` | `it` | レシーバー自身 | 副作用・ログ・デバッグ |
