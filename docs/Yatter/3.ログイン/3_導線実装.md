# 導線実装
ログイン画面とパブリックタイムライン画面の導線実装を行います。  
アプリを起動した時の挙動を変更します。

## 画面遷移の考え方（Navigation 3）

ログイン画面の導線実装に入る前に、Yatter で採用している **Navigation 3**（`androidx.navigation3:navigation3-runtime` / `navigation3-ui`）の考え方を整理します。

このセクションでは以下の3つの疑問に答えます。

1. **画面遷移はどういう仕組みで動いているのか？**
2. **画面間でどんな情報を渡せるのか？**
3. **実際にどうやって画面間で情報のやり取りを行うのか？**

> このセクションの一部のコードは説明用です。Yatterプロジェクトにはコピペしないでください（概念図・擬似コード）。

### 1. 画面遷移はどういう仕組みで動いているのか

#### そもそも画面遷移とは何か

Androidアプリで「画面が変わる」とは、表示される UI コンポーザブルが別のものに切り替わることです。

Navigation 3 では、**今表示する画面の履歴**を `rememberNavBackStack(initial)`が返す **バックスタック**（画面キーのリスト）として保持し、`NavDisplay`がその末尾に対応する UI を選んで表示します。

#### NavDisplay と画面キー（YatterNavKey）

`NavDisplay`は `entryProvider { entry<LoginKey> { ... } entry<PublicTimelineKey> { ... } }`のように、**`YatterNavKey`の型ごとに** どの Composable を出すかを登録するルーターです。画面の識別子は **`@Serializable` な `sealed interface YatterNavKey`**（例: `LoginKey`, `PublicTimelineKey`, `PostKey`, `YweetDetailKey(yweetId)`）で表します。

```
【バックスタックの例】
ユーザー操作: ログイン → パブリックタイムライン → 投稿画面へ進む

backStack のイメージ:
[ LoginKey, PublicTimelineKey, PostKey ]
                                    ↑ 現在表示（末尾）

端末の「戻る」で末尾を取り除く → PublicTimelineKey の画面が表示される
```

#### 遷移と戻る操作

進む操作は **`backStack.add(次の画面キー)`**、戻る操作は **`backStack.removeLast()`**（スタックが2件以上のとき）のように、**リストを直接操作**して表現します。`MainApp.kt`の `onBack` ラムダがこれに相当します。

`NavDisplay(..., onBack = onBack)`に渡すことで、システムの戻るボタンやヘッダの戻ると連動させます。

---

### 2. 画面間でどんな情報を渡せるのか

画面間で渡すのは **`YatterNavKey`のプロパティ**として表現できる **ID やプリミティブ** に留めるのが安全です。

```kotlin
// 例: ツイート詳細は ID のみをキーに含める（実装のイメージ）
@Serializable
data class YweetDetailKey(val yweetId: String) : YatterNavKey
```

**ドメインモデル全体をキーに埋め込まない** でください。詳細画面では ID だけ受け取り、ViewModel でリポジトリから取得する設計にします。

```
[避ける] Yweet オブジェクトを丸ごと次画面へ渡す
  → 状態保持・シリアライズが肥大化する

[推奨] yweetId だけキーに載せ、詳細画面の ViewModel で取得する
```

---

### 3. どうやって画面間で情報のやり取りを行うのか

ViewModelは **Composable やバックスタックを直接触れない**ため、「遷移してほしい」ことは **イベント通知** で UIに伝えます。Yatterでは次の流れです。

- ViewModel: **`Channel<〇〇Event>`** に `send` し、**`receiveAsFlow()`** で **`Flow<〇〇Event>`** として公開する
- Page: **`LaunchedEffect(viewModel) { viewModel.navigationEvent.collect { ... } }`** でイベントを受け取り、`MainApp` から渡した **`onLoggedIn` などのコールバック** を呼ぶ（`ViewModel`インスタンスが差し替わったときに購読をやり直すため、`Unit`ではなく `viewModel`をキーにする）
- MainApp: コールバック内で **`backStack.clear()` / `add(...)` / `removeLast()`** などを実行する

#### 処理の流れ（例: ログイン成功）

```
1. ユーザーがログインボタンをタップ
2. LoginViewModelが LoginUseCaseを実行し、成功なら _navigationEvent.send(LoginNavigationEvent.LoggedIn)
3. LoginPage が event.collect で受け取り onLoggedIn() を呼ぶ
4. MainApp が onLoggedIn = { backStack.clear(); backStack.add(PublicTimelineKey) } を実行
5. ログイン画面を履歴に残さずパブリックタイムラインへ切り替わる
```

#### 新しい画面を追加するとき

1. `YatterNavKey`にキー型を追加する（`data object` または `@Serializable data class`）。
2. `MainApp`の `entryProvider`に `entry<YourKey> { ... }`を追加する。
3. 遷移元の Page に `MainApp` からコールバックを渡し、ViewModelのイベントでそれを呼ぶ。

以上を踏まえて、次節から Yatter アプリの導線実装に入ります。

## パブリックタイムライン/ログインの導線実装

### 実装の概要
さて、Yatterアプリの実装に戻りましょう。

Yatterアプリで既にログインしていればアプリ起動時にはそのままパブリックタイムライン画面に遷移し、一度もログインしていなければログイン画面に遷移するような挙動にします。

ログイン済みかどうかを判定するために`CheckLoginService`を利用します。template にはすでに実装済みのため、ここではコードを確認して理解を深めます。`MainViewModel`でログイン状況を確認して遷移する画面を制御します。  

`CheckLoginService`の実装です。  
`CheckLoginService`はDomainServiceにあたるため、`domain/service`パッケージにinterfaceを定義し`infra/domain/service`に実装クラスを配置します。  

```Kotlin
// domain/service/CheckLoginService.kt

interface CheckLoginService {
  suspend fun execute(): Boolean
}
```

`CheckLoginServiceImpl`クラスの実装です。  
今回は認証情報がPreferencesに格納されているかどうかがログインを表していますのでそこを確認するように実装します。  

```Kotlin
// infra/domain/service/CheckLoginServiceImpl.kt

class CheckLoginServiceImpl(
  private val tokenPreferences: TokenPreferences,
) : CheckLoginService {
  override suspend fun execute(): Boolean {
    return tokenPreferences.getAccessToken().isNullOrEmpty().not()
  }
}
```

`CheckLoginServiceImpl`の実装が完了したら単体テストを書いてみましょう。  
（template にはすでに `CheckLoginServiceImplSpec` が用意されているため、時間がある方はコードを読んで理解を深めるか、自分でも書いてみてください。）  
今回のテストでは次の観点の確認ができると良さそうです。  

- TokenPreferencesに値が保存されていなければfalse
- TokenPreferencesに値が保存されていればtrue

次に、UI層で画面遷移の実装をします。Yatterでは **`YatterNavKey` + `rememberNavBackStack` + `NavDisplay`** で画面を切り替えます。

#### 画面キーと MainApp の対応（概要）

- `ui/navigation/YatterNavKey.kt` … `@Serializable sealed interface YatterNavKey : NavKey`
- `LoginKey.kt` / `PublicTimelineKey.kt` など … 画面ごとのキー
- `MainApp.kt` … `rememberNavBackStack(startNavKey)` + `NavDisplay` + `entryProvider { entry<LoginKey> { ... } ... }`

#### ログイン成功〜パブリックタイムライン表示

`LoginViewModel`は成功時に `Channel`へ `LoginNavigationEvent.LoggedIn`を `send` し、`navigationEvent: Flow<LoginNavigationEvent>`として公開します。`LoginPage`は `LaunchedEffect`で購読し、`MainApp` から渡した `onLoggedIn`を呼びます。`MainApp` 側で **`backStack.clear()`のあと `backStack.add(PublicTimelineKey)`** とすれば、ログイン画面をスタックから外してパブリックタイムラインへ遷移できます。

```kotlin
// LoginViewModel（抜粋）
when (result) {
  is LoginUseCaseResult.Success -> _navigationEvent.send(LoginNavigationEvent.LoggedIn)
  is LoginUseCaseResult.Failure -> { /* TODO */ }
}

// MainApp（抜粋）
entry<LoginKey> {
  LoginPage(
    onLoggedIn = {
      backStack.clear()
      backStack.add(PublicTimelineKey)
    },
    onNavigateToRegister = { /* 登録画面を作成したら繋ぎこむ */ },
  )
}
```

### 画面遷移の実装

まずは、アプリ起動時にログイン状態のチェックをして初期画面を決定するためのViewModelの実装を行います。  

`ui`パッケージに`MainViewModel.kt`ファイルを作成して、`MainViewModel`を定義します。  

```Kotlin
class MainViewModel : ViewModel()
```

`MainViewModel`ではログイン状況を確認するために引数に`CheckLoginService`を受け取ります。  

```Kotlin
class MainViewModel(
  private val checkLoginService: CheckLoginService,
) : ViewModel()
```

初期画面を UIに通知するため、**`StateFlow<Boolean?>`の `isLoggedIn`** を公開します。`null`の間は未確定（`MainApp`は早期 `return`で何も表示しない想定）、`true` / `false`が確定したらそれぞれ `PublicTimelineKey` / `LoginKey`を `rememberNavBackStack`の初期値に使います。

```kotlin
private val _isLoggedIn = MutableStateFlow<Boolean?>(null)
val isLoggedIn: StateFlow<Boolean?> = _isLoggedIn.asStateFlow()

fun onCreate() {
  viewModelScope.launch {
    _isLoggedIn.value = checkLoginService.execute()
  }
}
```

`MainViewModel`のテストでは **`isLoggedIn`が true / false に遷移すること** を検証します。

次に、各 Page への画面遷移を管理する `MainApp` Composable を定義します。
`ui`パッケージに`MainApp.kt`ファイルを作成してください。

`isLoggedIn`が確定するまで `return` し、`key(startNavKey)` 内で `rememberNavBackStack(startNavKey)`を生成してから `NavDisplay`を構成します。戻る操作は `onBack = { if (backStack.size > 1) backStack.removeLast() }`のように **リスト操作** で表現します。

また、各PageでViewModel以外の引数を持っている場合、引数を指定します。
今回の場合であれば、`LoginPage`はログインした時の処理`onLoggedIn`と登録画面に遷移するための処理`onNavigateToRegister`が必要です。
`onLoggedIn`は、ログイン後にタイムラインに遷移する必要があるため、`backStack.add(PublicTimelineKey)`を実行します。
また、すでにログインしているのに戻るキーを押してタイムラインからログイン画面に戻るなどが発生しないように制御するため、`PublicTimelineKey`をaddする前に`backStack.clear()`で履歴をクリアにしておきましょう。
`onNavigateToRegister`については、登録画面の作成がされていないため今回は何の処理も書きません。

これらを合わせると、現時点での`MainApp`は次のようになります。  
必要な import の例もあわせて示します。

```kotlin
package com.dmm.bootcamp.yatter.ui

import android.os.Build
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.key
import androidx.lifecycle.Lifecycle
import androidx.lifecycle.compose.LifecycleEventEffect
import androidx.lifecycle.compose.collectAsStateWithLifecycle
import androidx.navigation3.runtime.entryProvider
import androidx.navigation3.runtime.rememberNavBackStack
import androidx.navigation3.runtime.rememberSaveableStateHolderNavEntryDecorator
import androidx.navigation3.ui.NavDisplay
import com.dmm.bootcamp.yatter.ui.login.LoginPage
import com.dmm.bootcamp.yatter.ui.navigation.LoginKey
import com.dmm.bootcamp.yatter.ui.navigation.PublicTimelineKey
import com.dmm.bootcamp.yatter.ui.navigation.YatterNavKey
import com.dmm.bootcamp.yatter.ui.timeline.PublicTimelinePage
import org.koin.androidx.compose.koinViewModel

@Composable
fun MainApp(mainViewModel: MainViewModel = koinViewModel()) {
  val isLoggedIn by mainViewModel.isLoggedIn.collectAsStateWithLifecycle()
  LifecycleEventEffect(event = Lifecycle.Event.ON_CREATE) { mainViewModel.onCreate() }

  val startNavKey: YatterNavKey = when (isLoggedIn) {
    true -> PublicTimelineKey
    false -> LoginKey
    null -> return
  }

  key(startNavKey) {
    val backStack = rememberNavBackStack(startNavKey)
    val onBack: () -> Unit = {
      if (backStack.size > 1) {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.VANILLA_ICE_CREAM) {
          backStack.removeLast()
        } else {
          backStack.removeAt(backStack.lastIndex)
        }
      }
    }
    NavDisplay(
      backStack = backStack,
      onBack = onBack,
      entryDecorators = listOf(rememberSaveableStateHolderNavEntryDecorator()),
      entryProvider = entryProvider {
        entry<LoginKey> { 
          LoginPage(
            onLoggedIn = {
              backStack.clear()
              backStack.add(PublicTimelineKey)
            },
            onNavigateToRegister = { /* 登録画面を作成したら繋ぎこむ */ },
          )
        }
        entry<PublicTimelineKey> {
          // 4章で FAB 導線を追加するとき、ここで onNavigateToPost を渡します
          PublicTimelinePage()
        }
        // ほかの画面キーも同様に entry を追加
      },
    )
  }
}
```

> 新しい画面を追加するときは、`YatterNavKey`を継承したキーを追加し、`entryProvider`に `entry<...>`を追加してください。
