# パブリックタイムライン画面の実装
最初に実装する機能はパブリックタイムライン画面です。  
パブリックタイムライン画面は全ユーザーのツイートが流れるタイムライン画面です。  
デザインの指定はありませんが、X(Twitter)のような見た目を目指して実装を進めます。
